# Планировщик санаториев

Веб-приложение на Django для подбора санаториев и площадок и сборки маршрута. Пользователь задаёт бюджет за сутки, регион и пожелания. Приложение отбирает площадки, кратко объясняет выбор и по запросу сохраняет текст маршрута.

Интерфейс на русском языке. Демо-каталог — санатории Калужской области.

## Требования

- Python 3.14 или новее
- [Poetry](https://python-poetry.org/)

Зависимости ставятся в окружение Poetry. Команды `manage.py` запускайте через `poetry run`: пакет `dotenv` есть только там.

## Установка

В корне репозитория:

```text
poetry install
```

## Переменные окружения

Поиск, пояснения и текст маршрута обращаются к OpenAI-совместимому прокси. Создайте в корне файл `.env`. Он не коммитится.

```text
LLM_BASE_URL=https://proxy.example/v1
LLM_API_KEY=секрет
LLM_MODEL=имя-чат-модели
EMBEDDING_MODEL_NAME=имя-модели-эмбеддингов
```

`LLM_BASE_URL` — адрес API. Клиент вызывает `{LLM_BASE_URL}/chat/completions` и `{LLM_BASE_URL}/embeddings`. Если адрес уже заканчивается на нужный путь, он используется как есть. `LLM_MODEL` нужна для пояснений и маршрута, `EMBEDDING_MODEL_NAME` — для подбора. Ключ уходит в заголовке `Authorization: Bearer`.

Пустая или отсутствующая переменная останавливает запрос с ошибкой «имя не задан». Уже заданные переменные окружения файл `.env` не перезаписывает.

## База и каталог

База — SQLite, файл `db.sqlite3` в корне. Его создаёт миграция, в репозиторий он не входит.

```text
poetry run python manage.py migrate
poetry run python manage.py load_demo catalog/data/sanatoria.csv
```

`load_demo` читает CSV в UTF-8. Разделитель полей — запятая, десятичный разделитель — точка. Одна строка — одна площадка. Одинаковое `institution_name` собирает площадки в одно учреждение. Повторная загрузка обновляет учреждение и пару «учреждение + адрес». Ошибка в любой строке отменяет весь запуск.

Обязательные колонки: `institution_name`, `description`, `treatment_profile`, `address`, `latitude`, `longitude`, `transport_accessibility`, `min_daily_price`, `max_daily_price`, `procedures`, `excursions`.

Необязательные колонки:

- `season` — `круглый год`, `весна`, `лето`, `осень` или `зима`. Пустая ячейка означает круглый год.
- `limited_mobility_access` — `да` или `нет`, `1` или `0`. Пустая ячейка означает «нет».
- `rating` — целое число от 0 до 5. Ноль означает «не указан».

Если необязательной колонки нет в файле, при создании берётся значение по умолчанию, а при обновлении поле не меняется.

Без пути команда загружает короткий встроенный пример, а не каталог Калужской области:

```text
poetry run python manage.py load_demo
```

## Администратор

```text
poetry run python manage.py createsuperuser
```

Админка: <http://127.0.0.1:8000/admin/>.

Обычный пользователь регистрируется на `/register/` и входит на `/accounts/login/`.

## Запуск

```text
poetry run python manage.py runserver
```

Приложение открывается на <http://127.0.0.1:8000/>. Поиск, маршруты и список планов доступны только после входа.

На главной форме четыре поля помимо бюджета: регион, свободный текст, желаемые процедуры и экскурсии. Из результатов можно собрать маршрут. Сохранённые маршруты лежат на `/plans/`. Пользователь видит и удаляет только свои планы.

## Подбор

Бюджет — потолок цены за сутки: площадка остаётся, если её минимальная цена не выше бюджета. Регион ищется как подстрока адреса без учёта регистра, «е» и «ё» считаются одним знаком. Пустой регион площадки не отсекает.

Оставшиеся площадки ранжируются по похожести текста, процедурам, экскурсиям, транспорту, цене и рейтингу. В выдаче не больше пяти. Вектор площадки сохраняется и пересчитывается, когда меняется её текст или имя модели эмбеддингов.

Сезона и доступности для маломобильных в форме поиска нет. Эти фильтры включаются только аргументами `matching.engine.match`.

## Структура

| Каталог | Назначение |
| --- | --- |
| `catalog` | Учреждения, площадки, CSV и команда `load_demo` |
| `matching` | Фильтр, ранжирование, кэш эмбеддингов и клиент прокси |
| `planner` | Формы, поиск, маршруты и шаблоны |
| `sanatorium_planner` | Настройки Django и корневые адреса |
| `static` | Общие стили |
| `templates` | Базовый шаблон, вход и регистрация |

## Тесты

```text
poetry run python manage.py test
```

Отдельное приложение запускается так же, с именем `catalog`, `matching` или `planner`.
